# Site speed

How fast each page is for **real visitors**, measured in their own browsers. These are the Core Web Vitals Google uses as a ranking signal.

## The three main figures
- **Loading (LCP)**: how long until the main content, usually the hero image or heading, appears. Good: 2.5 s or less.
- **Responsiveness (INP)**: how quickly the page reacts to taps, clicks and typing. Good: 200 ms or less.
- **Visual stability (CLS)**: how much the page jumps around while loading. Good: 0.1 or less.

Each value is the **75th percentile**: 3 in 4 visits were at least this fast. Pages with few visits are marked with *, as their figures can still move.

## Using it
- Filter by **Phones** or **Desktop**; phones are usually slower and matter most to Google.
- The slowest pages are listed first. Common fixes: smaller hero images (WebP, under ~300 KB), fewer videos above the fold, and images with set sizes so the page doesn't jump.
- The same figures appear in each page's **SEO** block.

## Privacy
Only the page address, the timings and phone or desktop are recorded: no IP address, cookies or personal details. Data is kept for 90 days.
