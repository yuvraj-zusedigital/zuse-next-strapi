# Projects (Work and case studies)

A project is a tile on the **Work** grid and, optionally, a full **case study** page.

## The Work tile
- **Title**: the short name on the tile, e.g. "Komodo". **Tile label** is the text under it (leave it empty to show the project's categories).
- **Work tile media**: the poster image and an optional video that plays on hover. **Tile media type** chooses image or video.
- **Tile width**: full or half width. **Rank** sets the order (lower first).
- **Project categories** decide which category pages (Websites, Web Apps…) list the project.

## The case study page
- **Project details path**: the page's address, e.g. `/casestudies/web-apps/my-project/` (category, then slug). Leave empty for no page.
- **Case study title**, **description**, **banner** and **about** fill the top of the page; **Case study meta** is the details list beside the intro (a value with several lines shows as a list).
- **Case study blocks** tell the story: text (with optional bullet points), full-width images and image pairs. Blocks can be hidden with the eye button.
- **Testimonial**: pick one to show its quote at the end; leave empty to keep the built-in quote.
