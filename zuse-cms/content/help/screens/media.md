# Media library

All images, videos, audio and documents.

- **Upload**: drag files in or click Upload. Large files show progress.
- Click a file to edit its **name**, **alt text** (describes the image for screen readers and Google — always fill it in) and **caption**.
- The details show **where the file is used**. Deleting a used file removes it from those entries (Admins only).
- Search and filter by type to find files quickly.

## Viewing images full screen
- Click an image in a file's details, an image field, or the SEO share preview to open it full screen. In rich text, **double-click** an image (a single click selects it).
- Click the image or press **Z** to see it at full size; press **←** / **→** to move between images and **Esc** to close.
- The viewer shows the size, dimensions and alt text, and warns when alt text is missing.
