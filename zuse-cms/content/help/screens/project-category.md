# Project categories

The filters on the Work page and the category pages (`/casestudies/<slug>`).

- **Name**: the filter label, e.g. "Web Apps". **Slug**: its address, e.g. `web-apps`.
- **Rank**: the order in the filter and in the "other categories" lists (lower first).
- Add projects to a category from the project itself (**Project categories**).
- A new published category gets its own page automatically.
