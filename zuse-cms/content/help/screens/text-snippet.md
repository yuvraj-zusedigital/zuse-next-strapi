# Text snippets

Values you write once and use anywhere: on pages, in menus, in SEO titles and descriptions, and in blog posts and case studies. Admins only.

## The list
- **Snippet**: how you write it in content, e.g. `{phone}`.
- **Label**: a friendly name so everyone knows what it's for.
- **Value**: what visitors see in its place.

## Using a snippet
1. **New text snippet**: give it a **name** (letters and numbers, e.g. `phone` or `yearsInBusiness`), a **label** and a **value**.
2. In any text, write the name in curly brackets: `Call us on {phone}`.
3. Publish the page where you added it. Like any edit, it only reaches the live site once that page is published.
4. From then on, changing the value here updates every page that uses it straight away; no need to republish them.

## Good to know
- `{year}` is built in and always shows the current year, e.g. `© {year} Zuse Digital`.
- The page preview shows the filled-in values. A name with no snippet stays as typed, so check the preview for leftover `{…}`.
- `{name}` and `{year}` are reserved.
- Deleting a snippet makes `{its name}` show as typed again wherever it's used.
